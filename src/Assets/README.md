The built-in laser pistol uses `blaster-a.glb` from Kenney's Blaster Kit 2.1.

Source: https://kenney.nl/assets/blaster-kit
Archive: https://kenney.nl/media/pages/assets/blaster-kit/261d80a716-1753959510/kenney_blaster-kit_2.1.zip
License: Creative Commons Zero (CC0); the supplied notice is LICENSE.Kenney.txt.
The model and its supplied palette texture are embedded in the plugin, so
hyprpm and the standalone .so have the same model without an external path.
glTF-Transform `copy` embeds the original external image. No mesh changes.
